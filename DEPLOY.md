# 🚀 Smart Home VN Budget - Deployment Guide

## Quick Start (Run as Administrator)

### Option 1: PowerShell Script (Recommended)
```powershell
# Run in PowerShell as Administrator
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
cd D:\smarthome-vn-budget
.\deploy.ps1
```

### Option 2: Batch Script (Simpler)
```cmd
# Run in Command Prompt as Administrator
cd D:\smarthome-vn-budget
deploy.bat
```

---

## What the Scripts Do

| Step | Action |
|------|--------|
| 1 | Install Git, Node.js, GitHub CLI via winget |
| 2 | Initialize git repository |
| 3 | Create .gitignore |
| 4 | Commit all files |
| 5 | Create GitHub repository & push |
| 6 | Guide Cloudflare Pages setup |

## Manual Alternative (If Scripts Fail)

### 1. Install Prerequisites
- **Git**: https://git-scm.com/download/win
- **Node.js 18+**: https://nodejs.org/
- **GitHub CLI**: https://cli.github.com/

### 2. Initialize & Push
```cmd
cd D:\smarthome-vn-budget
git init
git add .
git commit -m "feat: initial release - Smart Home VN Budget"
gh auth login
gh repo create smarthome-vn-budget --public --source=. --remote=origin --push
```

### 3. Cloudflare Pages
1. Go to **https://dash.cloudflare.com/pages**
2. **Create a project** → **Connect to Git**
3. Select **smarthome-vn-budget** repo
4. **Build settings**:
   - Build command: `npm run build`
   - Output directory: `dist`
   - Node version: `18`
5. **Environment Variables** (Settings → Environment variables):

| Variable | Value |
|----------|-------|
| `GA4_MEASUREMENT_ID` | G-XXXXXXXXXX (from analytics.google.com) |
| `UMAMI_WEBSITE_ID` | Your Umami website ID |
| `UMAMI_SCRIPT_URL` | https://analytics.yourdomain.com/script.js |
| `SHOPEE_AFFILIATE_ID` | Your Shopee Affiliate ID |
| `LAZADA_AFFILIATE_ID` | Your Lazada Affiliate ID |
| `AMAZON_ASSOCIATES_TAG` | Your Amazon Associates tag |
| `GEARVN_REF` | Your GearVN ref code |
| `ANPHUOC_REF` | Your AnPhuoc ref code |
| `ALIEXPRESS_AFF_FID` | Your AliExpress EPN FID |

6. **Save and Deploy**
